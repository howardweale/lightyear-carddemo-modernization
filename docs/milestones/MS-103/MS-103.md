# MS 103 Offline cloud runner foundation

Reconciled October 14 2026.

The cloud-runner foundation prepares a route away from laptop-local campaign assets and keys. Phase 1 validates the proposed execution request offline and defines the infrastructure boundary. It does not provision a cloud environment or start a workload.

## Delivered capability

Offline admission binds the request, source commit, permitted window, attempt and witness to an independently selected policy. Go, witness and ledger authorities are separate for engineering, qualification and factory scopes. The injected GCP KMS adapter verifies returned signatures and is tested with fixture transports.

Terraform describes separated identities, retained input and evidence storage, and federation constraints. The Packer recipe describes a pinned offline image. The manual workflow is plan-only, has no cloud authentication or execution capability, and cannot turn a request into a VM launch. Federation is disabled by default and no signing grants are created by the definitions.

## Evidence and remaining work

The dedicated CI covers offline contracts, Terraform schema and mock-provider plans, and Packer syntax and validation. The integration adds the missing pinned YAML test dependency to both full-platform CI jobs; it does not remove any checks. These results are software and configuration validation, not a deployed-cloud acceptance test.

Phase 2 still needs the live controller and boot agent, atomic attempt claims, generation-bound object retrieval, a new cloud memory witness, retained heartbeats, deadline enforcement and complete provider inventory after deletion. Cleanup observations must be authenticated; caller-provided JSON cannot prove resource absence. AWS reproduction is a later boundary.

Billing/project selection, machine and image choice, region, retention, budget, key setup and any irreversible retention lock need their own deployment decisions. The proposed region and spending cap are review defaults. The October 14 merge authorization does not authorize resource creation, cloud signing, native campaigns or model calls.
