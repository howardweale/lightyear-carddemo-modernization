# MS 95 Mainframe delivery intake and replay

Reconciled October 14 2026.

This milestone gives a customer and delivery team a repeatable way to receive mainframe files, check that the delivery is complete, decode records and retain a replayable comparison. It connects the earlier decoder and batch-pack work to an operator workflow. The completed evidence is a public synthetic rehearsal; actual customer execution evidence is still needed.

## Delivered capability

The intake commands freeze and sign a delivery, report missing files or metadata, decode records and job logs, compare repeated runs, and measure before-and-after changes. Public source bindings cover INTCALC, POSTTRAN, CREASTMT and TRANREPT. The INTCALC bridge runs the existing Java candidate and signs a verdict that can be replayed without running it again. The other three jobs have observation support, not new Java candidates.

The carddemo-zos Control Tower workspace admits intake, normalization proposals, difference dispositions and evidence release. Its HTTP, event, MCP and export surfaces return controlled hashes, counts and statuses rather than record values. A normalization proposal does not change a verdict until the relevant signed decision is verified. Evidence release requires separate sponsor and authorizer decisions.

## Evidence and remaining work

The integrated public rehearsal covered three synthetic runs and 50 files with no intake gaps. The unchanged Java INTCALC candidate produced an equivalent fixture verdict that replayed offline. The synthetic expected outputs originated in the Python reference; they are not observations from z/OS. Tests also cover tampered evidence, stale or incorrectly scoped rules, protected record values and incomplete releases.

Customer qualification still needs complete transfer metadata, original binary before-and-after records, readable job output and actual date parameters. Ambiguous layouts and unsupported blocked or spanned framing remain refused. Public fixture exceptions do not become rules for customer data.
