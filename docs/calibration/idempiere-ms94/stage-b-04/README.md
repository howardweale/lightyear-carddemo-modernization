## Prospective analyses

intervals. Repair conversion divides repaired passes by cohort first attempts
classified execution-failure whose nonempty closed feedback was actually sent in
a subsequent builder invocation. Diagnostic coverage uses the same actual-delivery
rule across all cohort execution-failure attempts. Exported-but-unsent diagnostic
coverage is reported separately. An analyst selection saved without another builder
invocation is not delivery. Zero eligible failures makes conversion undefined.
Post-repair business failures are counted separately. Pilots contribute costs,
not effectiveness successes. Tokens distinguish total input, cached input,
uncached input and output; incomplete usage remains explicit. Agent, native,
preparation and independent replay costs remain separate.

below 20% means the diagnostic is insufficient. Unrepaired cases need classification
before another intervention. There is no automatic MS95 launch.
