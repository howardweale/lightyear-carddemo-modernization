# MS81 — Measured calibration and schema/session baselines

## Customer benefit

Measure whether comparator work actually improves coverage on the same source
estate, and inventory the database facts needed before promising a customer a
useful comparison.

## Delivered behavior

The pinned iDempiere replay reproduces the original 1,078-pair report, then runs
the parser extensions and the calibrated gate. Decided SQL units rise from
776 to 780 out of the same 111,293 in-scope units across both dialects. Unsupported
units fall from 6,595 to 1,405. Parser work alone does not increase decisions;
comparing a safe ordered prefix before a later mismatch supplies the four extra
decisions. No old decision or divergence is lost.

The parser retains deferred constraint and ENABLE/NOVALIDATE semantics, supports
Oracle grouped column drops and national-character declarations, and never
converts those unresolved domains into equality by deleting their obligations.
The original audit implementation and retained artifacts remain unchanged.

A schema/session baseline binds every input and records required columns and
source-located DDL. It leaves catalog completeness, triggers, constraints, row
policies, rewrite rules and session settings unknown until evidence is supplied.
The static numeric DML subset can consume complete contracts; stale facts, unknown
side effects and unsupported expressions remain unresolved. Entry facts expire
at schema/session/unknown operations.

## Evidence and limits

[Measured counts and explanation](../../calibration/idempiere/index.html),
[reproduction and context contract](../../decidability-instrument.md), and
[synthetic context fixtures](../../../spec/calibration/context/corpus.json).

The synthetic context test moves from zero to four decided units out of six,
retaining a one-cent mismatch and an unknown-trigger case. It is not customer
capture evidence. The iDempiere result still has 1,077 indeterminate pairs.
No native execution, customer qualification, or application-equivalence claim.

## Validation

Parser negative tests, complete-input/context binding checks, changed-value and
unknown-context controls, full pinned source reproduction, and unchanged retained
audit validation run in the calibration suites. CI replays the public pinned
source and compares the complete published measurement.
