## What was delivered

Business rules that MS 110 still ran through the statement engine are now ordinary, readable Java 21. Each Java method names the COBOL paragraph it replaces, so a reviewer can trace every rule back to its source.

- **Sign-on (COSGN00):** four credential and routing rules. The Java keeps the source's distinctions between all-spaces, all-LOW-VALUES and mixed input, uses locale-independent upper-casing, and keeps the submitted user ID after a rejected sign-on.
- **Account update (COACTUP):** twelve edit paragraphs, 1215 to 1280:
  - mandatory and yes/no fields;
  - required and optional alphabetic and alphanumeric text;
  - numeric and money values;
  - SSN, FICO score, US state code, and state-to-ZIP consistency.
