# MS 108 — status as of 20 October 2026

MS 108 recorded that CardDemo's overall migration remained indeterminate, with IMS and application behavior still open. This dated note updates that position without changing the original record.

- **Application behavior.** MS 110 proves application behavior for six screens: sign-on, menu, account view, account update, and the pending authorization list and detail. It covers 120 journeys and 678 interactions, compared through the API and a browser against the pinned COBOL, including the full PostgreSQL state after each interaction. MS 111 replaced the sign-on and account-update rules with hand-written Java while keeping that proof green.
- **Data access.** PR #367 made the access adapters read the migrated typed tables directly.
- **IMS.** IMS data in these proofs remains labelled synthetic rows. The forty-case IMS replay compares bytes and database state only for implemented operations.
- **Still open:**
  - the rest of the application;
  - native CICS, IMS and z/OS equivalence;
  - a customer dataset.

  Overall migration equivalence is therefore still not established.
