# LIGHTYEAR milestone documentation library

This library is the customer-readable body of record for MS #1 through MS #51. Every milestone is
published from one governed catalog in Markdown, Microsoft Word (`.docx`), and PDF.

**[Open the searchable milestone index](https://howardweale.github.io/lightyear-carddemo-modernization/milestones/)** to filter by milestone number, title,
customer value, capability, release, or roadmap phase.

The documents explain purpose, customer value, delivered capability, evidence posture, limitations, and
the relationship to earlier work. They do not override the underlying schemas, receipts, ledgers, tests,
or policy decisions.

## Build and verification

```bash
./milestone-documentation.sh verify
./milestone-documentation.sh build
```

Windows:

```powershell
.\milestone-documentation.ps1 verify
.\milestone-documentation.ps1 build
```

`verify` uses only the Python standard library. `build` requires the `docs` optional dependency set.

The content-addressed [manifest](https://github.com/howardweale/lightyear-carddemo-modernization/blob/main/docs/milestones/manifest.json) fails verification if a canonical source changes, an artifact is missing or modified, or an untracked milestone artifact appears.
