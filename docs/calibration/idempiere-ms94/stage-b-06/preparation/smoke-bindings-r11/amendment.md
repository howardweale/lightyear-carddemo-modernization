## Exact acceptance rule

The external JDI collector reads each observed definition's constant pool,
method bytecode, descriptors, modifiers, field metadata, defining-loader identity
and class-object identity directly from the suspended JVM. It invokes no target
method and reads no captured values for this proof. It captures every observed
definition, including hidden definitions, without a lambda-name filter.

A previously uncatalogued hidden synthetic definition gains forwarding-host
attribution only when all of these checks pass during offline replay:

1. Its raw method bytes decode to own final instance capture-field loads and/or
   typed argument loads, exactly one method invocation, then the matching return.
   Captures and arguments must each be used once, in declared order. All captures
   and arguments are forwarded. Casts, boxing, allocation, branches, stores,
   arithmetic, synchronization, constructors and any extra instruction fail.
2. The invocation's host is already in the exact compiled-class catalogue. Its
   class hash, constant-pool hash and invoked method hash must match. Framework
   hosts additionally require a plan-bound JAR path, member and entry hash, read
   from the pinned application image before candidate execution. JAR shadowing
   by mounts is rejected. The observed JAR hash is recorded in the signed receipt.
3. The hidden definition and host have the same JVM defining-loader identity.
4. For JDI's top-first stack, a stub at index `i` has that exact target class,
   method and descriptor at **index `i-1`, the immediately younger frame**.
   An absent, older, nonadjacent or mismatched target fails.
5. Raw-byte hashes, definition identity and both observed neighbors are committed
   into the signed collector receipt and a separate signed census record. Replay
   recomputes hashes and relations from the chained raw events and rechecks all
   rules. A signed observation alone grants no trust.

There is no `$$Lambda` or other name-pattern allowlist. The JVM hidden-definition
separator is a discovery prerequisite, never authority to accept a frame. A
verified forwarding stub targeting candidate code is attributed to the candidate.
Support remains support. Unsupported generated shapes, including arbitrary
LambdaForms or proxies, gain no forwarding trust through this amendment.

All existing static-catalogue and constant-pool checks remain. No static class is
newly exempted by an image digest. Existing handling of ordinary JDK/application
frames outside the required catalogue is unchanged; this is not qualification of
every loaded class. The full saved-frame census makes those limits inspectable.

## One fresh smoke group, also the census

The three fresh serial pairs are retained reference, duplicate invoice-line
mutant, and candidate null dereference with direct closed diagnostic delivery to
the zero-model sink. J1 predicates, candidate/support source bytes, private
inputs, pinned application/database images and real October clocks are inherited
unchanged. Trial finalization, replay and cleanup stay inside 7,190 seconds per
pair; candidate timeout is 1,800 seconds. There is one attempt per fresh slot,
no retry, restart or replacement. The group stops on its existing equipment,
evidence, unexpected-outcome or cleanup rules.

Every raw definition and recorded adjacency remains local whatever the outcome.
A signed census can be incomplete and never masquerades as successful replay.
Capture/replay failures retain the available event stream, failure and census
records. Private method bytes, archives, captures and inputs are not published.

The known `HierarchicalTestEngine.execute` constant-pool mismatch is **not fixed
or waived**. Its expected hash remains unchanged. Raw pool capture will support
diagnosis if it recurs, and replay will still reject it. Ordinary compiler lambda
adaptations may also fail the deliberately narrow forwarding rule. Thus this
group is a prospective smoke/census, not a promised qualification pass.

03:00 PDT). Seven hours allow the 21,570-second aggregate trial budget plus
