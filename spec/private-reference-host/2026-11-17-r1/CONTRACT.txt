Exact review-only proposal. This is not installation, account creation, PC
execution, private generation, freeze, decryption, model or spend authority.
No agent runs the tool. CI runs synthetic tests only, never the attended entry.

H1 supplies INSPECT and QUALIFY_PUBLIC on the selected dedicated Windows-account
and private WSL2 Engine profile. H2a owns framed-stream encryption and durable
ciphertext completion; H2b owns private reference orchestration and the human
generation-to-commitment sequence. No private-reference mode is in H1. This split
keeps the public host qualification independently reviewable and under 1500 lines.

Windows custody is Howard's private read-only inspection, not agent discovery.
Use the accepted H-A separate-account checklist: different standard private
Windows account; Codex account not administrator (including deny-only membership)
and outside docker-users; private account's separate WSL2 registration/backing-VHD
ACL; no broad or Codex-account access; no sync/backup; Codex stopped across all
sessions and background services throughout the window. Every required receipt
boolean must be true, unknown fails. Preflight joins operation, exact wrapper
commit/tree and private-profile commitment. All raw account/SID/path/process
evidence stays with Howard. Windows administrators, including Howard, are trusted.

Local admission: native Linux x86_64, WSL2 kernel, ext4 private filesystem, owner
0700 directory, no extra root ACL entries, no symlink or group-writable ancestor,
at least 20 GiB available. Standard Windows does not imply non-root Linux: Howard
must have read-only visibility into the private distro's existing service/socket
process state. Lack of visibility refuses; the tool does not elevate or install.
The private Engine must be the existing system Docker service. Join MainPID,
hash-pinned real dockerd executable, process root and mount namespace, and the
Unix socket's ss listener PID. Docker Desktop/proxies, remote endpoints, emulation,
Windows mounts and unrelated containers refuse. Use fixed explicit local socket,
minimal environment and a reviewed empty runtime CLI config, never a current
context or inherited DOCKER_HOST. Engine data-root must also be native ext4.
