# MS 97 Approved graph context and routing controls

Reconciled October 14 2026.

This milestone adds reviewed graph context to verification and factory work. The practical benefit is traceable retrieval: an agent can find public source relationships and approved lessons while the platform checks where that context came from, what it may disclose and whether approval is still valid. Retrieval controls are implemented; their effect on model quality or cost has not been demonstrated by a live evaluation.

## Delivered capability

Verify graph projections bind approved public sources and pass a protected-value scan before activation. Unknown provenance and private or runtime-only dependencies are excluded. Graph-off and graph-on tool surfaces remain distinct. A projection request does not grant its own approval.

Factory memory adds proposals, review, public-source links, hybrid retrieval and a live signed revocation channel. A host-owned watermark detects rollback, including across new reader processes. Missing enrollment or stale revocation state refuses use. The default search uses keywords and graph proximity; the optional model-backed adapter has separate pinned assets and admission requirements.

Routing admission verifies the approved policy and actual paired outcomes. The recorded rule requires a sample floor of 35 paired cases per cell and a Wilson 95 percent lower bound of at least 80 percent for each workload. Provider credentials use scoped leases; builder and verifier roles do not inherit them.

## Evidence and remaining work

The published tests cover source bindings, protected-value refusal, signed decisions, revocation, expiry, rollback, ranking, provider identity and routing admission. They do not establish a completed model matrix, memory A/B experiment, semantic search benchmark or cost-saving result. Abbreviation hypotheses remain unvalidated proposals.

Live deployment still requires separate host trust, keys, watermark enrollment and service activation. The retained Verify graph-stage record also leaves the separate Tower authority, real inventory leak scan and graph-on acceptance outstanding. The B07 graph-versus-search plan is a design selection, not an executed effectiveness result.
