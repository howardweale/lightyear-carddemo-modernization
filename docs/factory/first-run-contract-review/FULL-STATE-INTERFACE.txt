N07-C: whole-session capture and comparison components

Planned public CI uses the existing authorization-pages-and-fraud session,
15 interactions, a disclosed synthetic seed and exact Git bytes on POSIX/Windows.
The frozen Proof.start/inputs/step/expected_state, assertions, 153 source files,
case catalogue, thresholds and retained receipts are unchanged.
Not yet a private runner or qualified result; no private CLI or admission.

Ordering and custody
- Stage input/context/source commitment before Engine/oracle execution. A caller
  verifier must authenticate the exact ACK, then reauthenticate persisted bytes.
  Boolean/string approval is refused; a CI lambda is not authentication.
- Exclusively consume before oracle entry or replay. Faults cannot retry/reseed.
- Project initial parent/child/quarantine/identity rows from committed raw input,
  never candidate state. Shared frozen mapping/codec dependency is disclosed.
- Retain complete frames, effective attributes, cursor/message, program/COMMAREA,
  before/after table-state chain and private reference events, not seven fragments.
- Bounded immutable chunks/private RAM use the store interface. Encryption,
  authenticated ACK/results and production private-store custody remain unbound.

Planned M1 outcomes
MATCH requires all comparisons; MISMATCH is an observed frame/COMMAREA/state
inequality. After consumption, malformed data, timeout/interruption, adapter,
database, storage or artifact-binding errors yield FAULT. Invalid prerequisite
bindings refuse before consumption. A terminal record binds source/oracle/input
and retains the successfully compared prefix. Persistence failure leaves the
attempt consumed with a fixed refusal, never private exception text.
All outcomes retain qualified=false and unverified candidate/transaction/browser/
authentication flags. No score, qualification or execution authority follows.

Planned M2 snapshot
One repeatable-read/read-only transaction inventories all ordinary, partitioned
and materialized tables in all user schemas, including empty tables and all rows/
columns. Identifiers are schema-qualified; encoded non-public names avoid collision.
row_security=off and missing SELECT privilege fault instead of hiding rows.
Views, foreign tables and sequences fault as unsupported; catalogs/TOAST are
excluded. Empty databases and missing expected tables remain explicit inequalities.
This is supported table state, not DDL equivalence or concurrent-writer isolation.
Planned PostgreSQL negatives cover extra public/non-public tables, quoted names,
precise numeric decoding, missing tables, RLS/privilege denial and unsupported kinds.

Planned PostgreSQL relay observes one protocol-3.0 connection/original deadline;
COMMIT requires its backend tag plus idle ReadyForQuery; rollback/errors differ.
SSL/GSS, autocommit writes, ambiguous/incomplete messages, multiple connections,
COPY and suspended portals are refused. No private query/password/row logs.
Digest-pinned CI checks real commit/rollback/durable rows independently and consumed
initial loading; scripted full-session replay does not prove candidate/browser work.
Not yet same-request connection ownership, bypass prevention, authenticated
results, encrypted custody, native qualification or Howard private admission.
