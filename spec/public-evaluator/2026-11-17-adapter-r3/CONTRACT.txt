Public evaluator adapter (no PR yet, r3)
Exact standalone adapter library for build/evaluate_public controller ports.
No production Docker worker or LIVE bootstrap is supplied. This proposal is
not executable authority and does not reopen retired routes. A separately
reviewed worker must implement the contracts below before any real use.
The adapter hash-loads ONLY Claude's exact public suite6da875e2 and every joined
public input/hand output; output layouts pinned to CVACT01Y/CVTRA05Y. It never
accepts a suite merely because it is labelled public, and has no hidden port.
Existing public suite, source and expected outputs remain byte-identical.
Worker compile must attest javac phase, exact image/tool identity, no timeout,
daemon health and complete cleanup; anything absent/false is a terminal fault.
Exit0 BUILT; only exit1 COMPILE_FAILED;2/3/4/all others terminal. Diagnostic mode
must be javac-XDrawDiagnostics, source named Main.java or /source/Main.java.
Those flags belong to a future reviewed worker change, not an implicit change
to any existing gate. Only recognized candidate-source diagnostics are relayed;
all other stderr is replaced by compiler-diagnostic-unavailable, never raw text.
Messages strip paths/URIs, snippets/carets/stack traces, C0 exceptTAB/LF/CR; cap
512 canonical bytes, max4, sorted line/column/message hash. Unknown/truncated
messages set truncated. Over-redaction can lose useful diagnostics: named limit.
No model prompt may contain raw compiler stdout or private exception content.
evaluate_public supplies worker only input bytes and fixed clock, never hand
outputs. Worker runs every case against the exact build and returns complete
channels, identity/cleanup and receipt; infrastructure cannot become DIFFERENT.
Expected outputs are Claude's hand derivations, usable for LIVE only after the
separate GnuCOBOL reference qualification/three-way freeze criterion is adopted.
Files compare by record index and fixed copybook slices, missing/extra records
count different. Repeated FILLER slices form one field row per record (OR of
differences), not double counting. Empty-field rows count framing/count faults
once per case. Counts overlap across fields; never sum them as a case score.
stdout/stderr split LF only; final unterminated line counts. Exit one per case.
PC10/11/12 output files are unmodelled after abend and omitted as suite directs;
their stdout/stderr/exit remain compared. No warning suppression on candidate
stderr. Partial candidate records yield framing/field differences, not padding.
Rows ordered ACCTFILE,TRANSACT,stdout,stderr,exit then field lexical, max24,
whole-row truncation to4096 encoded bytes; keep exact source/suite hashes.
Public counts/diagnostics only, no values, case ids or record ids. Controller
performs its own closed schema and field allowlist check (Patch B r2).
retain callback must durably store exact public evidence and read back its hash.
This module retains a hash-only observation receipt; complete raw public
observations must be retained by the trusted worker for independent review.
Tests use synthetic workers and public suite only, no sockets/compiler/Docker.
Before push after Patch B, rebase once and review exact tree; one PR in CI.
No spend, model calls, signing, activation, dispatch, push or execution here.
