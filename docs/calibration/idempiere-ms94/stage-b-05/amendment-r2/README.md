MS94 B05 pre-outcome amendment r2

The original approved plan and declaration remain byte-identical. Before any B05 model call, this amendment replaces r1 campaign termination on equipment suspicion or repeated unresolved causes with a signed operator review pause after trial finalization and before the next fresh slot. A repeated candidate business mistake is not established equipment failure. Each fingerprint counts once per trial; attempts in one trial never match one another.

A signed continue decision with a reason advances to the next fresh slot and changes no verdict. It is not a replacement, restart or resumption. Stop ends the campaign incomplete; void records a void campaign. Both preserve every outcome. Decisions are operator review, not independent. Waiting consumes the existing 26-hour campaign budget. Infrastructure, provenance, evidence, cleanup, calendar and hard-deadline failures still stop and void.

The finalization-inclusive 7190-second trial deadline, 600-second finalization reserve, 115 calls, 69 compilations, 26 hours, and per-trial 5 calls/3 compilations remain unchanged. No primary metric or verdict changes: final cohort pass rate with Wilson 95% interval, pilots excluded, no pooling with B03. Original B04 remains VOID. No model launch is authorized by this amendment.
