# Human-signed public clean-control pilot — unexecuted draft

This is the first positive execution checkpoint for the human-admission route.
It is not a strict P5 pass and cannot close G0, D01, D07 or D08 by itself.
The dispatch integration remains separately subject to exact-hash approval.

The smallest case uses one public source file which already satisfies a real
deterministic OCI gate. The native controller makes exactly one scripted planner
call, verifies the baseline, makes no edit and returns a passed native receipt.
The public response script binds the exact invocation, schema and response hashes;
no wildcard invocation, model endpoint, machine signer or fake proof is allowed.
