PLACEHOLDER REVIEW DRY RUN / NOT RUNNABLE

This CI job evaluates simulated review observations against the decisions in
COMMAND-SHEET and RETURN-CHECKLIST. It does not run their shell blocks, inspect a
Mac or USB, launch S1-S6, or establish physical state, custody or cleanup.
DRY-RUN-RULES maps each negative fixture to an exact source phrase. The retained
JSON names every STOP decision and the unchanged expected S4-S6 FAIL outcomes.
A matching simulated control grants no execution authority. Missing observations
stop; missing anchors fail CI. Human comparisons remain human comparisons.
Existing public-IO CI tests exercise the separate IO implementation.
